🖥️ MiniVM Integrity Checker

A register-based virtual machine executes an embedded bytecode program that validates your passphrase byte-by-byte.

Category: Reverse Engineering  |  Difficulty: Hard

ISA Quick Reference

0x01  LOAD_IMM  dst, imm       R[dst] = imm
0x02  LOAD_MEM  dst, src_a     R[dst] = mem[R[src_a]]
0x04  ADD       dst, src_a     R[dst] += R[src_a]
0x05  XOR       dst, src_a     R[dst] ^= R[src_a]
0x06  CMP_EQ    dst, src_a     R[dst] = (R[dst]==R[src_a]) ? 1 : 0
0x07  JMP_IF    dst, imm       if R[dst]==0: PC += imm
0x08  HALT
0x09  IN        dst            R[dst] = next input byte
0x0A  OUT       src_a          accept/reject signal
